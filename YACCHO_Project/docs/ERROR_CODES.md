# YACCHO Error Codes

## Current Status

v0.3 does not yet have a finalized, stable public error-code specification.

## Planned Error Categories

- LEX：字句解析エラー
- PAR：構文解析エラー
- SEM：意味解析エラー
- TYP：型エラー
- RUN：実行時エラー
- MEM：メモリ関連エラー
- MOD：モジュール関連エラー
- PKG：パッケージ関連エラー
- SEC：セキュリティ関連エラー

## Future Requirements

- Error code
- Error message
- Source file
- Line and column
- Error explanation
- Suggested fix

日本語と英語のエラーメッセージに対応する。
